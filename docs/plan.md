# 오늘은 너로: 기획서 v1 (추첨 돌림판)

작성 2026-11-07. 배포 실습 앱 4번. 디자인 시안(휴대폰 넷 + PC 하나) `../디자인/오늘은너로_시안.html`

## 한 줄

> 점심 메뉴, 발표 순서, 이번 주 당번. 고민될 때 돌리는 돌림판. 항목은 화면에서 바로 바꾸고, 주소 하나로 내 돌림판을 팀에 보낸다.

## 왜 이걸

- '오늘 뭐 먹지'는 꾸준한 직장인 고민이고, 점심값이 오르며 더 자주 고민한다(업무지구 점심 1만 원 기사, 2025-07)
- 네 앱 중 유일한 '누르는 도구'. 작은 절(두드리기), 여덟 글자(계산), 초대 페이지(읽는 한 장)와 겹치지 않는다
- data.js가 항목 배열 하나라 수강생이 가장 쉽게 '내 것'으로 바꾼다. 바꾸는 순간 팀에서 바로 쓴다

## 누가, 언제

| 사용자 | 순간 | 바라는 것 |
|---|---|---|
| 점심 메뉴 못 정하는 팀 | 11시 50분 | 10초 안에 정하고 나가기 |
| 회의 진행자 | 발표 순서, 당번 정할 때 | 공정해 보이게, 화면 공유로 같이 보기 |

## 1분 흐름

```
첫 화면(오늘의 점심 돌림판) → [돌리기] → 3초 회전, 째깍 소리 → 결과 크게("오늘은 김밥!")
   → 다시 돌리기 / 이번 것 빼고 돌리기 / 결과 복사
   → [항목 바꾸기] → 목록 편집(추가, 삭제) → [이 돌림판 공유] → ?items=… 주소 복사
```

## 화면

| 화면 | 하는 일 | 핵심 요소 |
|---|---|---|
| 1 돌림판 | 돌리기 | 돌림판(항목 2~12개), 위쪽 바늘, 큰 돌리기 버튼, 위에 주제 고르기(점심, 발표 순서, 당번) |
| 2 결과 | 결과 보기 | 결과 크게, 작은 축하 효과, 다시 돌리기, 이번 것 빼고, 결과 복사 |
| 3 항목 바꾸기 | 편집 | 항목 목록(지우기), 추가 칸, 색 자동, 초기화 |
| 4 공유 | 내 돌림판 보내기 | 항목이 담긴 주소, 복사, QR 없음(링크만) |

## PC 화면 (반응형)

- 1280px 이상: 왼쪽에 큰 돌림판, 오른쪽에 항목 목록과 최근 결과 기록. 회의에서 화면 공유하기 좋게 돌림판이 화면 높이를 채운다
- 스페이스 키로 돌리기, 키보드로 항목 추가
- 휴대폰: 돌림판 위, 버튼 아래. 편집은 아래에서 올라오는 시트

## 범위

| 꼭 (이번에) | 다음 | 안 함 |
|---|---|---|
| 항목 2~12개 돌림판, 회전과 감속, 결과 | 무게(자주 나오게) 설정 | 경품 추첨용 공정성 보장(기록과 검증 서버) |
| 주제 셋 미리 넣기(data.js) | 사다리 타기 모드 | 실시간 여럿이 같이 보기 |
| 화면에서 항목 편집, localStorage 저장 | 다국어 | 광고, 로그인 |
| 주소 쿼리로 공유(`?items=`), 결과 복사 | 소리 끄기 저장 | |

## 데이터 (data.js)

```
PRESETS = { 점심:['김밥','라멘','샐러드','국밥','버거','쌀국수'], 발표순서:['A','B','C','D'], 당번:['월','화','수','목','금'] }
COLORS = [...8가지], SPIN = { seconds:3, sound:true }
```

## 기술

- 돌림판: SVG 부채꼴(항목 수에 맞춰 각도 계산) + CSS transform 회전. 결과는 먼저 무작위로 고르고, 그 칸에 멈추는 각도로 감속(ease-out)
- 무작위: `crypto.getRandomValues`(발표 순서 같은 공정성 안내에 근거)
- 소리: Web Audio로 짧은 째깍 소리(바늘이 칸을 넘을 때)
- 공유: `?items=` 쿼리를 `encodeURIComponent`로. 받은 쪽은 쿼리가 있으면 그 항목으로 시작
- 움직임 줄이기 설정을 켠 사람은 회전 없이 바로 결과
- 파일: index.html, style.css, app.js, data.js, og.png, README.md. 외부 라이브러리 없음

## 디자인 방향

- 톤: 밝고 경쾌한 도구. 흰 바탕, 진한 남색 글자, 칸 색은 부드러운 여덟 가지(채도 낮게), 버튼 강조는 한 가지
- 글꼴: Pretendard, 결과 글자는 아주 크게
- 칸 글자는 항상 대비 4.5:1 이상(밝은 칸에는 진한 글자)

## 배포 실습 포인트

1. data.js의 점심 목록을 회사 근처 식당으로 바꿔 푸시 → 팀 채널에 주소 공유
2. 주소 뒤 `?items=`로 서버 없이 데이터를 실어 보내는 원리 설명
3. 선택: 주제를 하나 더 만들어(예: 회의실 청소 당번) 브랜치로 미리 보기 배포

## 위험과 표현

- 경품 추첨처럼 결과에 이해관계가 걸린 곳에는 쓰지 말라는 안내(브라우저에서 돌아가 결과를 바꿀 수 있다)
- 사람 이름을 항목으로 넣을 때는 동의, 공개 주소에 남지 않게 '공유 주소에 이름이 담긴다'는 안내
